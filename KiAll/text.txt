
## 🚀 Быстрый старт

1. Скопируйте все файлы в одну папку
2. Откройте `index.html` в браузере
3. Чат готов к использованию!

## ✨ Особенности

### 🎯 Основные функции
- **Локальный режим** - работает без интернета
- **Умные ответы** на вопросы по программированию
- **Примеры кода** HTML, CSS, JavaScript
- **История сообщений** с сохранением в localStorage
- **Адаптивный дизайн** для всех устройств

### 🔧 Режимы работы
1. **Локальный режим** (по умолчанию)
   - Ответы на базовые вопросы
   - Примеры кода
   - Советы по программированию

2. **API режим** (требуется пополнение баланса)
   - Полноценный AI ассистент
   - Генерация сложного кода
   - Развернутые объяснения

### 🎨 Интерфейс
- Современный дизайн с градиентами
- Анимации и плавные переходы
- Индикатор статуса API
- Примеры запросов для быстрого старта
- Настройки чата (звуки, автоскролл, история)

## 🔧 Настройка API

### Требования для работы API
1. Аккаунт на [platform.deepseek.com](https://platform.deepseek.com)
2. API ключ с пополненным балансом
3. Минимальный депозит: $5-10

### Восстановление работы API
Если API не работает (ошибка 402):

1. Перейдите на [platform.deepseek.com](https://platform.deepseek.com)
2. Войдите в свой аккаунт
3. Перейдите в раздел "Billing"
4. Пополните баланс
5. Вернитесь в чат - API заработает автоматически
